ROLE: SENIOR ARCHITECTURAL VISUALIZER, BIM MODELLER,

3D ENVIRONMENT ARTIST

PROJECT:
DISRUPT — ARCHITECTURAL 3D VISUALIZATION
REFERENCE FILE:
Disrupt_Architectural Working set _060326.pdf

I am uploading a 23-page architectural working drawing set
for the Disrupt building.

Your task is to transform these architectural working drawings
into a highly accurate, professional, enterprise-level 3D
architectural visualization and building massing model.

This is NOT a conceptual redesign.

This is an ARCHITECTURAL RECONSTRUCTION AND VISUALIZATION
TASK based on the provided working drawings.

Your highest priority is:
1. Architectural accuracy
2. Dimensional consistency
3. Correct building proportions
4. Correct floor relationships
5. Correct facade and opening placement
6. Professional-quality 3D output
7. Clear documentation of uncertainties

Do not rush directly into generating an attractive image.
First understand the building completely.

============================================================
PHASE 1 — COMPLETE DRAWING ANALYSIS
============================================================

Read and analyze ALL 23 PAGES individually.

Do not skip pages because they appear repetitive or contain
technical drawings.

Create a structured architectural analysis report.

Identify and document:

A. PROJECT IDENTIFICATION
- Project name
- Client
- Architectural consultant
- Structural consultant
- Drawing set title
- Drawing numbers
- Drawing revisions and dates, if visible
- Any project information visible in title blocks

B. FLOOR PLANS

Analyze each floor separately:

GROUND FLOOR:
- Overall building footprint
- External wall arrangement
- Internal room layout
- Room names and functions
- Entrance and exit locations
- Main circulation routes
- Staircases
- Voids and double-height areas
- Courtyards or open spaces
- Toilets and service spaces
- Door locations
- Window locations
- Any visible structural elements
- Any special architectural features

FIRST FLOOR:
Perform the same analysis.

SECOND FLOOR:
Perform the same analysis.

For every floor, identify how it connects vertically to the
other floors.

C. DIMENSIONS AND SCALE

Identify every readable critical dimension.

Determine the dimensional units ONLY from the drawings or
reliable drawing information.

Do NOT assume dimensions are in millimetres, metres, feet,
or inches without evidence.

If the units cannot be established:
- State that clearly.
- Identify the affected dimensions.
- Request clarification where necessary.

Prioritize verification of:
- Overall building length and width
- Floor-to-floor heights
- Ceiling heights, where shown
- Wall thicknesses
- Door widths and heights
- Window widths and heights
- Stair dimensions
- Major room dimensions
- Parapet heights
- Roof levels
- External projections

Important:
The drawing notes indicate that the drawings should not be
scaled and that stated dimensions must be used.

Never estimate dimensions from the visual size of a scanned
drawing when a stated dimension is available.

D. ELEVATIONS

Analyze all four elevations:

PAGE 15 — FRONT ELEVATION (A-201)
PAGE 16 — LEFT ELEVATION (A-202)
PAGE 17 — RIGHT ELEVATION (A-203)
PAGE 18 — BACK ELEVATION (A-204)

For each elevation, identify:

- Overall building height
- Number of visible levels
- Floor slab lines
- Parapets
- Roof configuration
- Window arrangement
- Door arrangement
- External wall finishes
- Vertical and horizontal architectural features
- Projections and recesses
- Screens, louvers, shading devices
- Balconies or terraces, if shown
- Any visible architectural details
- Alignment with the floor plans

Do not invent architectural features.

If an elevation conflicts with a floor plan:
- Identify the exact conflict.
- Reference the relevant page numbers.
- Explain what needs clarification.
- Do not silently choose one version.

E. SECTIONS

Analyze:

PAGE 19 — SECTION A-A (A-301)
PAGE 20 — SECTION B-B (A-302)

Extract and document:
- Floor-to-floor heights
- Finished floor levels
- Slab thicknesses, where shown
- Ceiling heights
- Roof and parapet heights
- Vertical circulation
- Building section profile
- Major structural and architectural relationships
- Any double-height spaces
- Any critical level differences

Use the sections to validate the 3D building height.

Do not create building heights based only on visual estimation
from elevations.

F. DOOR, WINDOW & SHADING DETAILS

Analyze:

PAGE 21 — A-601 (GROUND FLOOR)
PAGE 22 — A-602 (FIRST FLOOR)
PAGE 23 — A-603 (SECOND FLOOR)

Identify:
- Door types
- Window types
- Door/window sizes, if readable
- Shading details
- Repeated architectural components
- Any special facade systems
- Any details affecting the 3D exterior model

Explain how these details should be incorporated into the
building visualization.

PHASE 2 — DRAWING COORDINATION & ACCURACY CONTROL
============================================================

Before creating the 3D model, prepare a COORDINATION MATRIX.

Cross-check the following:

1. Ground floor plan vs front elevation
2. First floor plan vs front elevation
3. Second floor plan vs front elevation
4. All floor plans vs left elevation
5. All floor plans vs right elevation
6. All floor plans vs back elevation
7. Floor plans vs sections
8. Floor plans vs door/window details
9. Floor levels vs section heights
10. Window and door positions across all relevant drawings

Create a list of:
- Confirmed information
- Unclear information
- Conflicting information
- Missing information
- Assumptions that would be required

DO NOT make silent assumptions.

If a missing detail has no significant effect on geometry,
you may propose a clearly labelled provisional assumption.

If it materially affects the building's shape, facade, height,
or proportions, ask me for clarification before modelling it.

============================================================
PHASE 3 — BUILDING GEOMETRY & 3D MODEL
============================================================

After completing the analysis and resolving critical
uncertainties, create the 3D building model.

The model must follow the working drawings, not generic
architectural design conventions.

REQUIRED GEOMETRY:

- Accurate overall building massing
- Correct floor slab elevations
- Correct wall thicknesses wherever specified
- Correct roof/parapet geometry
- Correct door and window openings
- Correct stair and void locations
- Correct major projections and recesses
- Correct alignment between floors
- Correct facade proportions
- Correct relationship between internal and external spaces

Every visible architectural opening should be based on the
working drawings.

Do not add:
- Decorative windows
- Unspecified balconies
- Unspecified roof structures
- Invented columns
- Invented facade ornaments
- Unspecified landscaping
- Unspecified architectural features

If something is not shown, do not automatically invent it.

For geometry that cannot be verified, maintain a clearly
documented assumption rather than presenting it as confirmed.

============================================================
PHASE 4 — EXTERIOR MATERIALS & DESIGN INTERPRETATION
============================================================

Analyze the drawings to determine the architectural language
and materials that can reasonably be identified.

Identify, where supported:
- Concrete
- Plaster/render
- Brick
- Stone
- Metal
- Glass
- Timber
- Paint finishes
- Shading elements
- Roof materials

Do not arbitrarily assign expensive or decorative materials
just to make the render look attractive.

If materials are not specified or cannot be identified:
- Clearly state that.
- Provide a neutral, professional material interpretation.
- Label it as a visualization assumption.
- Preserve the original architectural design.

The final building should look like a realistic professional
architectural visualization, not a generic AI-generated house.

============================================================
PHASE 5 — PHOTOREALISTIC 3D EXTERIOR RENDERS
============================================================

Create professional-quality exterior visualization views.

REQUIRED VIEWS:

VIEW 1 — FRONT ELEVATION
- Camera aligned with the front facade
- Architectural proportions preserved
- Straight, controlled perspective
- All facade openings clearly visible
- Professional daylight lighting

VIEW 2 — REAR ELEVATION
- Camera aligned with the back facade
- Accurate rear openings and geometry
- Same material and construction logic

VIEW 3 — LEFT SIDE
- Show left-side facade
- Preserve window and wall placement

VIEW 4 — RIGHT SIDE
- Show right-side facade
- Preserve window and wall placement

VIEW 5 — THREE-QUARTER AERIAL VIEW
- Show the overall building massing
- Reveal the relationship between floors
- Show roof configuration
- Professional architectural visualization camera
- Do not use an angle that hides critical architectural elements

VIEW 6 — EYE-LEVEL ARCHITECTURAL VIEW
- Professional human-scale camera
- Show the primary approach and entrance
- Realistic lighting and material response

VISUAL QUALITY:

Aim for a professional architectural visualization standard.

Use:
- Physically plausible lighting
- Realistic material textures
- Correct scale relationships
- Natural shadows
- Accurate reflections
- Realistic glass
- Clean geometry
- Controlled exposure
- Professional camera composition
- High-resolution output where supported

Avoid:
- Overly dramatic cinematic effects
- Excessive fog
- Unrealistic lighting
- Distorted perspectives
- AI-generated architectural artifacts
- Random furniture or people that obscure the building
- Invented design features

Keep the immediate building surroundings minimal and neutral
unless the drawings provide site context.
